# Casino Trainer App Website

This public repository hosts the public customer support page and the legal privacy policy documentation for the **Casino Trainer** mobile app. 

## Deployment
This project is configured to deploy automatically via **GitHub Pages**. 

* **Live Support URL:** https://github.io
* **Live Privacy Policy URL:** https://github.io

## Core App Stack Details
* Built using **Capacitor**
* Targeted Platform Tracks: Android (Google Play) & iOS (Apple App Store)
* Framework Architecture: Native WebView Container
